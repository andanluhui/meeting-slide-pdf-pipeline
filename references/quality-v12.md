# v1.2 质量增强与 Agent 自检指引

## 保守自动布局

- `--layout auto`（默认）：先保守裁黑边，再比较多组相邻帧的**空间运动差异**，只有在存在连续且清晰的侧栏分界线、幻灯片主体相对稳定、另一侧持续运动等多项证据时，才自动裁掉讲者侧栏。
- `--layout blackbars`：只裁黑边，不识别讲者侧栏。
- `--layout full`：始终保留完整原始画面。
- `--crop x,y,width,height`：Agent 核对预览后在必要时指定，优先级最高。
- 对低置信度、画中画覆盖、背景视频、全屏摄像头、边框不明显的页面，优先**保留完整画面**，并在质量报告中提示 Agent 进一步复核。不要声称所有录播都能准确自动裁剪。
- `*-layout.jpg` 红框表示实际用于输出的裁剪区域，可以据此手工调 `--crop`。

## 短暂幻灯片与去重

- 固定采样默认 `--fps 2`（上限 5），为降低短暂页面漏检，额外启动基于 FFmpeg 原始帧率的场景切换检测；可 `--no-scene-boost` 禁用以降低运行成本。
- `--scene-threshold 0.13` 是粗粒度场景切换阈值：数值调低容易多检并显著增加解码时间和审查工作量，调高容易漏掉小范围变化。
- 原始帧率场景检测也**不能保证**捕获仅持续极短时间、内容变化极小、过渡动画覆盖、编码损坏或视频本身未保存的页面。重要场合由 Agent 在具备源视频访问权限时对照源视频核查；无法核查时，应说明限制。
- 不丢弃只出现一次的页面。生成的候选页按时间排序去重，逐页时长不足 1.25 秒时标记为需要复核，不自动删除。

## PDF 核查

运行后由执行的 Agent 自行查看三个内部核查文件（通常不向用户逐一交付）：

1. `*-layout.jpg`：核对幻灯片区域的红色边框是否错误裁掉内容。
2. `*-contact.jpg`、`*-contact-002.jpg` 等：所有候选页面的缩略图按时间展开，**不截断前 120 页以外的内容**。
3. `*-slides.json`：`quality.alerts` 是全局复核提示，`quality.pages[].review_flags` 是逐页标记，主要包括短页、过长时间没有换页、低细节疑似空白等；`layout.candidates` 为布局候选。

`review_flags` 不是“确定漏页”的判断，也不代表检测到的页面都是正确幻灯片。数据用于确定复核优先级。对所有重要视频，Agent 应尽可能结合原视频复核；自动标记不是准确率保证。

## 自动章节的性质

- 已知演讲或章节时间点：优先 `--chapters examples/chapters.example.json`，精度由提供的时间点决定。
- `--auto-chapters`：生成**低置信度的视觉章节建议**，并按建议生成分章节 PDF。只识别相隔至少 120 秒、较明显的标题/版式重置，不识别真实讲者、学术主题、会议议程。
- 如果无法确定章节边界，只会得到从视频开头开始的一个章节；不能根据输出的分段文件自动认定章节完整或正确。
- 正式归档前由 Agent 优先核对建议位置；无法确认主题或讲者归属时，保留低置信度提示，不冒充准确分章。必要时修改 JSON 并用 `--chapters` 重跑。

## 测试与限制

`python -m unittest discover -s tests -v` 包括合成视频及本地 HTTP 直链回归测试，但不等于使用真实会议、多种编码器、多个云平台或全部 Windows/macOS/Linux 环境的验证。质量模型仍是可复核的启发式规则而非经验证的识别准确率。

## 给用户的默认交付

仅提供用户要求的 PDF 或章节 PDF。缩略图、裁剪预览和 JSON 属于内部自检材料，不默认向用户解释或要求用户逐项审核。Agent 应自行处理可解决的质量问题并重跑；若仍存在重要的不确定性，简明告知实际限制或请求必要的帮助，不得声称保证零漏页。
